# 原典、分章与现代翻译的质量标准

## 来源

古典原著属于公有领域。本项目原典及现代译文初版引用 [Scagin/CCTC lunyu/part1.json](https://github.com/Scagin/CCTC/blob/master/lunyu/part1.json)，上游声明MIT许可；完整许可与原署名见仓库根目录THIRD-PARTY-NOTICES.md。不可将上游翻译称为本项目原创。

传统《论语》二十篇的分章数量、字形、标点、引句和版本存在差异，可参考中文维基文库《論語》与《論語集注》校订。**数据分段≠权威章序。**

## 四层模型

1. 20篇通行顺序（项目导航）。
2. 616条上游原文—译文配对单元（原始数据层）。
3. 在标点句数和回拼一致时拆解成更多句卡；不可靠的维持原配对。
4. AI Skill 引经：仅使用核实过的真实原文与篇名；严格章号需先声明底本。

## 人工复核重点

- 「说/悦」「弟/悌」「知/智」「女/汝」等传世阅读字形与释义差别。
- 「仁」「礼」「君子」「小人」等词在先秦语境与现代意思不必一致。
- 译文可能存在争议性解释、现代化过度、忽略原句条件或上下文错配；应逐句复核。
- 要求二人复核时，建立见证版本、差异、注释证据与reviewStatus。

不要把结构测试通过等同于文字考据完成。
