# 设计系统 · 儒家竹影与宣纸

## 视觉主旨

整体视觉以“学而时习，温故知新”为引导。偏雅正、平衡、留白；避免将儒家文化简单表现为生硬的说教或压迫性宫廷图案。视觉主体：墨绿色竹节、朱砂红日轮、暖色宣纸、书法式宋体标题。

字体：系统宋体/衬线回退呈现标题与经典正文，导航与操作控件使用系统无衬线。无需传输第三方字体文件。

## 叙事层次

1. 首页超大“论语。”、竹影、朱砂日轮、双语小字。
2. 仁、学、礼三个核心主题。
3. “温故而知新”静态引言。
4. 20篇目录网格与全文搜索。
5. 逐条阅读室：篇目导航、原典在上、点击揭晓译文在下。

## 响应式

大屏四列目录卡片，左侧篇目导航+右侧单列阅读流。手机两列目录，篇目导航横向滚动，原文译文**始终上下**，绝不能拆为平行双栏。

动效仅用于营造轻盈进入感，不遮挡阅读信息。系统prefers-reduced-motion启用时关闭装饰性动画，保持控件可用。
