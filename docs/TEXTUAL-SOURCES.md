**不得声明这些现代译文由本项目原创，也不得把开源许可当作翻译绝对准确的保证。**

## 20篇与分章争议

《论语》通行二十篇的篇序较稳定，但不同底本与注本的“章”数可能不同。部分维基文库通行阅读本按501章整理；朱熹《论语集注》等注本采用其他分章方法。历史上还有简帛文字异同，不能将本项目616个上游分段编号冒充朱熹本或维基文库的标准章号。

参考查阅：
- [中文维基文库《論語》](https://zh.wikisource.org/wiki/論語)
- [中文维基文库《論語集注》](https://zh.wikisource.org/wiki/論語集注)
- [中国哲学书电子化计划《论语》](https://ctext.org/analects/zhs)

这些是交叉核对的研究入口，本文并未逐篇声明校核完成。

## 需要逐字检查

- 说/悦、弟/悌、知/智、女/汝等字词在不同阅读文本中的区别。
- “仁”“义”“礼”“君子”“小人”等语词需结合先秦语境，不能直接按现代口语定义。
- 同一章包含多人对话、互相关联的问答时，现代标点切分不等于独立论点。
- 现代译文的句号和古文句号未必对齐；已经采取保守配对机制，但标点数量相同也不能取代人工审校。

## 研究工作流

固定一个真实文献版本和稳定修订号/出版书目 → 对照文字异同 → 记录标点、译法争议 → 标记人工审核状态 → 第二人交叉复核 → 合入数据和测试。引用AI回答时若未核实具体章号，只引用确认的原文和篇名。
