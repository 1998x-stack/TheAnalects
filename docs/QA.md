# 测试与验收矩阵

## 自动化

npm test检查：20篇的通行次序、616组非空原译配对、1,013张由对应关系生成的句卡、每组双向逐字回拼、无重复句卡ID、首页和章节导航的DOM绑定、译文初始hidden与可访问控件、不使用innerHTML、必备文件齐全。

npm run build将index、CSS、JS、assets和所有data模块复制到dist目录，并检查关键资源文件存在。

这些检查**不证明**翻译在学术上完全正确、自动切分语义必然一致，也不证明实际浏览器无障碍、部署状态或公网可访问性。
